## Sobre mim

Sou desenvolvedor full-stack e estudante de **Análise e Desenvolvimento de Sistemas**. Construo software de ponta a ponta: modelo o banco, escrevo a API, desenho a interface e entrego algo que roda, seja no navegador, no Windows ou no Android. Também tenho olho de designer, e isso aparece no acabamento dos meus projetos.

- 🛠️ Hoje trabalho em um **ERP modular** para a rede interna de uma clínica e em uma **plataforma de monitoramento (RMM)** para várias empresas
- 🎮 Desenvolvendo o **Hubify Gaming** (comunidades, voz e chat) e o **Lê+**, leitor de ebooks com narração offline
- 📡 Interesse especial em **tempo real** (WebRTC, Socket.IO) e **arquitetura de backend** (DDD, Spring Boot)
- 🤝 Aberto a oportunidades, colaborações e revisão de código
